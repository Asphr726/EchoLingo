## Executed cleanup

After confirming the published release and updater, ran:

```sh
conda run -n echolingo-spike1 python scripts/clean_workspace.py
conda run --no-capture-output -n echolingo-spike1 python scripts/clean_workspace.py --apply --release-tag v0.4.0
```

Removed `target/`, root/desktop `node_modules/`, frontend `dist/`, generated
Tauri schemas and Python/test caches. Workspace recovery: **7,672,754,176
bytes (7.15 GiB)**. Also removed 38 exact task-created temporary paths,
including the duplicate vision dependency directory, temporary Node cache,
editing scripts, failed-build logs and verification downloads: **254,533,632
bytes**. A tiny ignored timestamp/UUID-only test session marker was removed.
Combined measured recovery: **7,927,287,808 bytes (7.38 GiB)**.

The workspace is approximately **135 MiB** afterward. Source, Git history,
lockfiles, agent instructions, credentials/signing keys, Conda environments,
model weights and roughly 120 MiB of historical benchmark/replay evidence in
`runs/` are preserved. No indiscriminate Git clean or global cache purge ran.
`AGENTS.md` now requires this verified post-release cleanup for future work;
the cleanup script defaults to dry-run and refuses tracked files/symlinks.
Build/test dependencies must be regenerated before the next local build.
