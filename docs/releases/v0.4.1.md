# EchoLingo 0.4.1 Beta — visual request fix

Published on 2026-11-13 at 02:32:21 UTC (2026-11-12 Los Angeles):
[GitHub Release](https://github.com/Asphr726/EchoLingo/releases/tag/v0.4.1).
Release source/tag commit: `1492b137dbbfb8aaac3273e52f57dc4444c2d678`.
The fix is in `c07ec69406805fd1b7f8329f13090ce68ff7cc1d`: visual callers no
longer pass an unsupported `disable_thinking` argument to `ChatClient.complete()`.
That method already disables thinking. The 0.4.0 defect prevented image HTTP
requests entirely and surfaced as a page-1 reading failure; it also affected
unknown-model capability probes and crop checks.

Versions agree across Python, Cargo, npm, Tauri and lockfiles. Regression tests
use the production client with only HTTP transport mocked, actual PDF rendering,
capability probing and crop verification. The packaged runtime now includes an
offline `visual_requests` self-test covering all three production callers.
